# 加拿大 IRCC ATIP / GCMS Notes 中文申请指南

> 非官方个人经验分享｜最后核对：2026 年 7 月

本项目整理了通过加拿大 Access to Information and Privacy（ATIP）渠道申请 IRCC 移民/公民申请记录的一般步骤，包括 Applicant 自行申请和由他人代为申请时的常见填写思路。

## ⚠️ 阅读前请注意

- 本指南不是加拿大政府或 IRCC 的官方材料，也不构成法律、移民或个案建议。
- 页面、资格、费用、表格及处理方式可能随时变化，请始终以加拿大政府和 IRCC 官网当时显示的内容为准。
- ATIP 主要用于请求既有记录，**不能加快移民申请处理，也不等同于催签或普通进度查询**。
- 请勿在 Issue、评论区或私信中公开 UCI、Application Number、生日、地址、邮箱、电话、护照、签名或证件。
